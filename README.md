# BooksCollector

Система управления коллекцией книг с возможностью назначения жанров и работы с избранным.

## Описание

`BooksCollector` — класс для организации и управления коллекцией книг. 
Возможности:
* добавлять книги в коллекцию
* назначать жанрам книги
* получать книги по жанру
* работать со списком избранных книг

Файл tests.py содержит набор тестов, для основные проверок


## Функции

1. **`add_new_book`**  
   Добавляет книгу (до 40 символов, без дубликатов).

2. **`set_book_genre`**  
   Устанавливает жанр 

3. **`get_book_genre`**  
   Получает жанр книги.

4. **`get_books_with_specific_genre`**  
   Выводит список книг с указанным жанром.

5. **`get_books_genre`**  
   Показывает словарь 

6. **`get_books_for_children`**  
   Возвращает книги бподходящие для детей

7. **`add_book_in_favorites`**  
   Добавляет в избранное (если книга есть в `books_genre`, без дубликатов).

8. **`delete_book_from_favorites`**  
   Удаляет книгу из избранного

9. **`get_list_of_favorites_books`**  
   Получает список избранных книг
